===== rtl/universal/cheekyms/cheekyms_sound.sv =====
//============================================================================
//
//  Universal Cheeky Mouse sound board, discrete (5 V)
//  Copyright (C) 2026 Rodimus
//
//  From MAME nl_cheekyms.cpp (Vas Crabb, Couriersud): the schematic transcribed as a netlist.
//    port 40: D7 music (straight into the mix), D6 cheese, D5 hammer, D4 mouse dies, D3 pest dies, D2 mouse, D1 pest
//    port 80: D1 coin / extra, D0 mute (0 = Q1 shorts mix node A)
//  cheese:     transistor B-E noise, x101 then x1000 (LM324, ~1 kHz bandwidth), clipped; IC1 sets the bias so it
//              only swings while cheese = 1
//  mouse:      555 1k / 68k / 0.01u, RESET = mouse, CONT from RESET through R14 4.7k || D4 (C13 10u): rising glide
//  hammer:     free-running 555 1k / 150k / 0.01u through IC5b: out = 2 V+ - V, V+ = C16 (0.1u, R23 1M) pulled to
//              ~1.4 V by IC1 / D5 / D6 while hammer = 1
//  pest:       free-running 555 1k / 68k / 0.01u, CONT warbled by a 16 Hz 555 (20k / 10k / 2.2u) through D7 /
//              R28 / R29 (C18 10u); IC5a gate as hammer (C20 0.22u, R35 1M)
//  mouse dies: 555 1k / 33k / 0.01u, RESET = mouse dies, CONT from RESET through R38 560 (C22 47u)
//  pest dies:  555 1k / 47k / 0.033u, RESET = pest dies;   coin / extra: 555 1k / 47k / 0.01u, RESET = coin
//  Mix: node A (R12 / R13 / R17 / R39 / R42 100k, R24 / R34 51k, Q1) -> R43 10k -> node B (R46 100k coin,
//  VR1 1k); solved: VB = 500 * sum(V / R) + 0.00946 * Vcoin. Output = VR1 wiper (VB / 2), MAME scale.
//  Engine: as rtl/zerohour/zerohour_sound.sv (32 clocks per step, v += (x * a) >> 32, 1 V = 2^24).
//
//============================================================================


===== rtl/universal/cosmic/cosmic_board.sv =====
//============================================================================
//
//  Universal Cosmic boards (Space Panic, Cosmic Alien, Magical Spot, Devil Zone, No Man's Land)
//  Copyright (C) 2026 Rodimus
//
//  From MAME cosmic.cpp / cosmic_v.cpp (Nicola Salmoria, Lee Taylor).
//
//  kind: 0 panic, 1 cosmica, 2 magspot, 3 devzone, 4 nomnlnd.
//  Video 10.816 MHz / 2 = 5.408 MHz (fractional enable from 19.656 MHz), 352 x 262, visible x 0-255, y 32-223.
//  Z80 10.816 MHz / 6 (panic, cosmica) or / 4 (magspot family).
//    panic / cosmica: 0000-3FFF ROM, 4000-5FFF video RAM, 6000-601F sprites, 6800-6803 inputs,
//                     7000-700B sound, 700C-700E colour registers, 700F flip, 7800-7801 sound (panic)
//    magspot family:  0000-2FFF ROM, 3800-3807 coinage DIP bits, 4000-401F sprites, 4800 DAC (nomnlnd 480A),
//                     4807 background enable, 480C-480D colour registers, 480F flip, 5000-5003 inputs,
//                     6000-7FFF video RAM
//  Interrupts: panic RST 08 at line 0 / RST 10 at line 224 (held to the acknowledge); cosmica coin = NMI;
//  magspot / devzone coin 1 = IRQ (RST 38), coin 2 = NMI; nomnlnd coin = NMI.
//  Picture (MAME): background (cosmica stars / devzone grid) < 1bpp bitmap coloured by the user1 map < 8
//  sprites (16x16 / 32x32, Y flip) < nomnlnd trees and river. Game flip mirrors bitmap, grid and trees, not
//  the sprites or stars; CRT Flip mirrors the logical raster (visible area symmetric).
//  Stars: the IC11 map latch is the PROM byte at the last x1 = 32n crossing (closed form, mirror-safe).
//  Grid: the RLE PROM is decoded once per frame in vblank into a frame RAM (read mirrored when flipped).
//
//============================================================================


===== rtl/universal/cosmic/cosmica_sound.sv =====
//============================================================================
//
//  Universal Cosmic Alien sound board (7910-S)
//  Copyright (C) 2026 Rodimus
//
//  Effect structure from the Cosmic Alien manual sound schematic (p.26): pins 1-12 = 7000-700B (data != 0),
//  pin 13 = the coin switch. Pitches and time constants fitted to recordings of the board (MAME 'cosmica'
//  samples), as for rtl/cosmic/panic_sound.sv:
//    background (while enabled): IC5b ~11 Hz samples the noise onto the IC5a 556 CV -> random pitch steps
//    dive A (pin 1): 3150 Hz, falling to ~2300 Hz after 1.5 s of hold
//    dive B (pin 3, select G.S.B / M.S.B / L.S.B on pins 4-6): one-shot sweep 5.6 kHz -> 700 Hz (tau 0.69 s);
//      L.S.B adds noise FM, G.S.B + L.S.B adds a 7 Hz chop (IC11b)
//    fire (pin 7): high noise burst; explosions: pin 8 loud (low noise, 2.3 s), pin 9 small (0.26 s) per the
//      schematic labels (MAME's cosmica_sound_output_w has offsets 7 / 8 the other way round)
//    extend (pin 10) / coin (pin 13): IC7b 556 tone, 1026 Hz 25 % pulse (as measured on the Space Panic copy
//      of the same circuit)
//    pin 12 sound enable: IC1 shorts the mix bus while low
//  Engine as rtl/zerohour/zerohour_sound.sv (32 clocks per step, v += (x * a) >> 32); envelopes 1.0 = 2^24.
//
//============================================================================


===== rtl/universal/cosmic/magspot_sound.sv =====
//============================================================================
//
//  Universal Magical Spot / Devil Zone sound board (8013 / 8022, identical)
//  Copyright (C) 2026 Rodimus
//
//  From the Magical Spot manual sound schematic (p.16) and main block diagram (p.18): two LS259s latch D7 of
//  4800-480F; pins: 4800 music (1), 4801 BGM (2), 4802 firing (3), 4803 laser ship explosion (4), 4804 cocoon (5),
//  4805 hit 2nd (6), 4806 UFO (7), 480E Ultramoth (8), 4809 Ultramoth (9), 480A hit 1st (10), 480B enable (11);
//  pin 13 coin pattern = the coin switch. No reference recordings exist (MAME: 1-bit DAC only); component values
//  from the schematic, VDD 12 V, Vref 6 V.
//    noise: 2SC945 junction noise x100 x1000 = white (clipped); Sallen-Key 51k / 51k / 0.022u / 0.1u x11 = pink
//    BGM: IC12b 11.8 Hz pulse samples pink onto the IC12a 556 CV (1k / 470k / 0.01u); IC11 low-pass (100k || 6800p)
//         gated by C18 (re-armed through D1 at every sample, R21 100k): plucked random notes
//    firing: white noise band (1-3 kHz) gated by C23 (1u, 100k / 100k)
//    Ultramoth: IC15 555 (1k / 75k / 4700p) CV swept by C24 (2.2u, 100k), white-noise jitter (R99 510k),
//         heard while pin 8 is high (IC9)
//    coin pattern: IC3a starts the 4040 on the coin edge, clocked by the 11.8 Hz pulses; Q1-Q4 through
//         100k / 51k / 24k / 12k = 4-bit CV of IC16b (1k / 51k / 0.01u), 16 notes; R53 10k (the loudest input)
//    UFO: IC16a 556 (1k / 100k / 0.01u) CV warbled by the 5.9 Hz IC3b toggle (10k / 22u)
//    cocoon: IC18a 556 (1k / 51k / 3300p) gated by C38 (1u)
//    hit 1st: IC8 556 (1k / 51k / 0.047u) CV = C34 (1u, R70 100k) + pink; gated by the same voltage
//    laser ship explosion / hit 2nd: pink noise gated by C36 (4.7u) / C40 (1u)
//    music: the CPU's bit through 100k / 51k, low-passed (C42 read as 0.0022u: 0.022u would leave ~70 Hz)
//           mixed at twice the R92 220k weight (HW 2026-10-12: about half as loud as it should be)
//    enable: Q2 shorts the mix bus
//  Engine as rtl/zerohour/zerohour_sound.sv (32 clocks per step, v += (x * a) >> 32, 1 V = 2^24).
//
//============================================================================


===== rtl/universal/cosmic/nomnlnd_sound.sv =====
//============================================================================
//
//  Universal No Man's Land sound board (8003)
//  Copyright (C) 2026 Rodimus
//
//  From the No Man's Land manual sound schematic (p.10); latch map as the Magical Spot main board (D7 of
//  4800-480F): 4800 attack march enable (1), 4801 L.S.B (2), 4802 G.S.B (3), 4803 tank drive (4), 4804 enemy
//  supplement (5), 4805 round clear (6), 4806 firing (7), 480E got enemy (8), 4809 player dead (9), 480A music
//  (10, MAME's DAC), 480B sound enable (11); pin 13 coin accept = the coin switch. No reference recordings
//  (MAME: 1-bit DAC only); component values from the schematic, VDD 12 V.
//    noise: 2SC945 x100 x1000 (a few kHz wide) -> R43 10k / C15 0.1u = pink (4 Vp-p)
//    attack march: IC13a 556 (1k / 75k / 1u) tempo, CV from L.S.B / G.S.B (100k / 51k); CD4040 Q1-Q8 through
//         eight 10k -> CV (1k / 10u) of IC13b 556 (1k / 200k / 0.01u); pin 1 low holds the 4040 in reset
//    tank drive: IC6a 556 (1k / 470k / 0.1u) / 2 (IC7a) through 51k / 1u -> CV of IC10a 556 (1k / 100k / 0.1u)
//         rumble, plus IC10b 556 (1k / 100k / 0.001u); both run while pin 4 is high
//    enemy supplement / round clear: 8-step pattern of the second 4040 (Q1-Q3 ^ round clear through 51k / 100k /
//         51k) on IC6b 556 (1k / 51k / 0.01u), clocked by IC6a
//    firing: IC11a 556 (1k / 200k / 0.01u) CV = C12 (1u, R33 330k), gated (R38 / R39 10k) by the same voltage
//    got enemy: IC11b 556 (1k / 100k / 0.01u) while pin 8 is high
//    player dead / coin: pink noise x10 / x4.7 gated by C16 (2.2u, 470k + 470k) / C18 (0.47u)
//    music: C35 / R60 straight into the bus; enable: IC16 shorts the bus after R50 / C17
//  Engine as rtl/zerohour/zerohour_sound.sv (32 clocks per step, v += (x * a) >> 32, 1 V = 2^24).
//
//============================================================================


===== rtl/universal/cosmic/panic_sound.sv =====
//============================================================================
//
//  Universal Space Panic sound board (8015)
//  Copyright (C) 2026 Rodimus
//
//  Effect structure from the Space Panic manual sound schematic (p.20): pins 1-12 = 7000-700B (data != 0),
//  pin 16 player die = 7800, pin 19 enemy laugh = 7801, pin 13 coin = the coin switch, pin 11 music = 700A D7.
//  The scan does not resolve every value, so pitches and time constants are fitted to recordings of the board
//  (MAME 'panic' samples): 556 tones -> square voices, transistor noise -> white noise through one-pole filters,
//  the op-amp gates -> RC envelopes. One-shot effects follow the sample lengths; held ones (falling, oxygen,
//  escape, extend) sound while their input is high, as on the board.
//    walk 882 Hz 25 % pulse (15 ms pulses + ~8 ms tail)      up/down 75 Hz, 35 ms        enemy die 1/2: high-pass noise 1.1 s
//    falling 1700 -> 90 Hz (tau 0.69 s)           oxygen 130 Hz, 0.4 s on / 0.2 s off
//    hang 280 Hz, 0.42 s                          escape low noise chopped at 3.2 Hz
//    extend 2594 Hz                               player die low noise, up 0.4 s then down
//    enemy laugh 1-3 kHz noise chopped at 4.4 Hz, 2.78 s                    coin 1026 Hz, 0.5 s
//  Engine as rtl/zerohour/zerohour_sound.sv (32 clocks per step, v += (x * a) >> 32); envelopes 1.0 = 2^24.
//
//============================================================================

===== rtl/universal/docastle/docastle_board.sv =====
//============================================================================
//
//  Universal 8302 board (Mr. Do's Castle, Do! Run Run, Wild Ride, Jumping Jack, Kick Rider)
//  Copyright (C) 2026 Rodimus
//
//  From MAME docastle.cpp (Brad Oliver) and the Mr. Do's Castle service manual schematics.
//
//  Clocks: 4.000 MHz for both Z80s, 9.828 MHz video crystal / 2 = pixel clock (here 19.656 / 4),
//  HD6845S CRTC at pixel / 8 (one character = 8 pixels). The game programs the CRTC.
//
//  map_mode 0 (MAME docastle_state):   main 0000-7FFF ROM, 8000-97FF RAM, 9800-99FF sprites,
//      A000-A7FF latch, B000/B800 video RAM, B400/BC00 colour RAM, E000 sub NMI;
//      sub 0000-3FFF ROM, 8000-87FF RAM, A000-A7FF latch, C000-C007(+C080) inputs / flip,
//      E000/E400/E800/EC00 SN76489A.
//  map_mode 1 (MAME dorunrun_state):   main 0000-1FFF ROM, 2000-37FF RAM, 3800-39FF sprites,
//      4000-9FFF ROM, A000-A7FF latch, B000 video RAM, B400 colour RAM, B800 sub NMI;
//      sub 0000-3FFF ROM, 8000-87FF RAM, A000/A400/A800/AC00 SN76489A, C000 inputs / flip,
//      E000-E7FF latch.
//  idsoccer (MAME idsoccer_state): main 0000-3FFF / 6000-9FFF ROM, 4000-57FF RAM, 5800-59FF sprites,
//      A000 latch, B000/B800 video RAM, B400/BC00 colour RAM, C000 ADPCM status / control, E000 sub NMI;
//      sub as docastle; sprite layout with tile bits 8-9 and no Y flip; MSM5205 at 384 kHz / 48;
//      second joystick on TMS1025 port 4; sprite graphics byte-wide (8 reads per row).
//  pri_low: tile pens 0-7 drawn over sprites (dorunrun_state), else pens 8-15 (docastle_state).
//
//  Main <-> sub: one bidirectional latch; a main access holds main WAIT until the sub CPU
//  accesses the latch (MAME main_from_sub_r / main_to_sub_w).
//  IRQs (as MAME): main IRQ = CRTC VSYNC; sub IRQ on HSYNC when MA6 rises, held until acknowledged;
//  sub WAIT = any SN76489A not READY. Inputs through two TMS1025 multiplexers (read returns the
//  port selected by the previous access). The sprite CPU (pass-through to the CF37201 sprite chip)
//  is not modelled: as in MAME, the main CPU's sprite writes go straight to sprite RAM.
//
//============================================================================


===== rtl/universal/ladybug/crt_flip_fb.sv =====
//============================================================================
//
//  CRT Flip for the Lady Bug video unit (Lady Bug, 8203 boards)
//  Copyright (C) 2026 Rodimus
//
//  The 8106-B / 8203-B sprite engine renders bands ahead of the beam from
//  block-chained sprite RAM, so its picture cannot be mirrored by remapping
//  coordinates (as on Mr. Do!). Instead the visible 240 x 192 picture (8-bit
//  colour codes) is double-buffered and, with CRT Flip on, read back from the
//  opposite corner: one frame of delay, flipped only. Off = straight through.
//  One pixel of latency either way.
//
//============================================================================

===== rtl/universal/ladybug/ladybug_clk.sv =====
//============================================================================
//
//  Lady Bug board clock enables
//  Copyright (C) 2026 Rodimus
//
//  Video enables follow Arnim Laeuger's ladybug_clk.vhd (FPGA Lady Bug, 2005):
//  the system clock is 4x the pixel clock, so clk_en_10mhz / clk_en_5mhz keep
//  their original names but run at 9.828 MHz / 4.914 MHz from a 19.656 MHz clock
//  (board: 9.828 MHz crystal / 2).
//
//  The CPU has its own 4 MHz crystal on the 8106-A2 board, so its enables come
//  from a fractional accumulator instead of the video divider: 4 MHz average,
//  cpu_cen_p = rising edge, cpu_cen_n = falling edge (T80pa), half a period apart.
//
//============================================================================

===== rtl/universal/ladybug/ladybug_cpu_unit.sv =====
//============================================================================
//
//  Lady Bug CPU unit (Universal 8106-A2 CPU board)
//  Copyright (C) 2026 Rodimus
//
//  Structure from Arnim Laeuger's ladybug_cpu_unit.vhd (FPGA Lady Bug, 2005)
//  and its MiSTer port by Sorgelig. The Z80 is T80pa with real rising/falling
//  half-cycles at 4 MHz (the old port used a patched T80a whose half-cycle
//  was one 20 MHz clock).

//  8000-9FFF I/O (x0-x3 IN0/IN1/DSW0/DSW1, x5 PAL protection 0x3E, x6/x7 sound
//  latches low/high), no flip latch / sound chips at A000-CFFF, IRQ on vblank
//  held until acknowledged (MAME irq0_line_hold), no coin chutes.
//
//============================================================================

===== rtl/universal/ladybug/sraider_overlay.sv =====
//============================================================================
//
//  Space Raider starfield + grid, mixed under the Lady Bug video
//  Copyright (C) 2026 Rodimus
//
//  From MAME sraider.cpp / zerohour_stars.cpp (Frank Palazzolo):
//  - stars: 17-bit LFSR stepped once per slot of a 256x256 raster starting at
//    (offset & 0xFF, offset >> 8); a star where (state & 0xFF) == 0xFF and the
//    feedback bit is 0, on pixels with bit 4 of (x + 8) == bit 0 of y (no VA bit).
//    Two alternating fields: state 0 / 0x1FC71, offset += speed * 2 - 9 every
//    second frame. Clipped to x <= 0xD8 (flipped: x >= 0x27).
//  - grid: 1bpp gfx3 tilemap (bottom half = top half mirrored) plus a full-height
//    line at every x whose grid RAM byte is non-zero, both in the grid colour.
//  - priority: chars/sprites > grid > stars > background.
//
//  Output is a colour code (so the CRT Flip frame buffer stays 8 bits wide):
//    {2'b00, r[1:0], g[1:0], b[1:0]}  Lady Bug pixel (2-bit DAC levels)
//    {2'b01, 3'b000, r, g, b}         grid (full on / off per gun)
//    {2'b10, 1'b0, colour[4:0]}       star (MAME sraider_palette star colours)
//
//  The overlay runs one pixel behind the Lady Bug output and tracks MAME screen
//  coordinates (visible x 8-247, y 32-223) of the pixel it holds. The LFSR is
//  advanced to the first visible slot during vblank (up to 65535 steps, one per
//  clock) and by 16 extra steps in each hblank.
//
//============================================================================

//    0000-5FFF ROM (H6, J6, L6)          6000-63FF RAM, mirrored at 6400 (2x 2114)

//  Latch 2: Q0 / Q5 / Q6 star speed, Q1 thrust (Zero Hour) / sprite bank (Red Clash), Q2 sound enable,

//
//  Universal Zero Hour sound board (8011), discrete
//  Copyright (C) 2026 Rodimus
//
//  From the Zero Hour manual sound schematic (p.25). Inputs from the main board LS259s (main block diagram):
//    latch 1 (5000) Q0-Q7 -> pins 1-8, latch 2 (5800) Q1-Q4 -> pins 10-13, VDD 12 V.
//    pin 1  shoot:          LM3900 VCO, C16 charged while high, falling sweep (C16 0.47u, ~91 ms)
//    pin 2  asteroid hit:   LFSR noise gated by C8 (400k * 1u); a CD4013 toggled at each end of pin 2 switches
//                           C7 (0.01u) onto the noise node (dull / bright halves)
//    pin 3  asteroid mod.:  phi1 + phi2 mixed into the asteroid noise (CD4016)
//    pin 4  enemy descend:  556 (C 0.1u), CV = C14 (1u, 1M) decaying after the trigger
//    pin 5  shield hit:     556 (C 3300p), CV = C21 (1u, 470k) charging after the trigger, phi7 warble
//    pin 6  noise burst:    LFSR noise (R1 C1 low-pass) through IC5a while high (16 ms pulses in MAME)
//    pin 7  enemy fire:     556 (C 2200p), CV = C9 (1u, 2.2M) rising while high, phi6 warble
//    pin 8  bonus warn:     556 one-shot (100k, 0.01u) fired by phi2, width set by alpha (phi9 low-passed)
//    pin 10 thrust:         LFSR stage 13 shifted through IC7 (2 stages) by an LM3900 VCO whose input is C6
//                           (22u, 150k): ~5.4 kHz falling to ~40 Hz over 10 s
//    pin 11 sound enable:   Q4 shorts the mix bus while low
//    pin 12 1-bit output:   straight into the mix (C25, R87)
//    pin 13 coin:           556 (C 3300p), CV = C24 (1u, 1M) decaying after the trigger, phi6 warble
//    (no pin)               556 (C18 3300p) gated by C20, restarted by every phi12 falling edge (~7.4 s)
//  Clock: CD4070 RC oscillator, 4.4 kHz (bonus warn = phi2 = f/16 = 275 Hz in the reference recording),
//  CD4020 phi1 = Q1, phi2-phi11 = Q4-Q13, phi12 = Q14 / 2; CD4006 LFSR, feedback stage 5 ^ stage 17.
//
//  Analog nodes: one RC / integrator engine, 32 clocks per step (dt = 1.628 us): v += (x * a) >> 32,
//  voltages in 2^24 units. 556s: cap between CV / 2 and CV; CV pin loading by the internal 5k divider.
//  Mix bus: R76 1k || R72 1k, x100 (R71 / R72): source weight 50k / R, C26 high-pass, LM324 swing.
//
//============================================================================
