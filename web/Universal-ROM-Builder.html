Which ROM set do I need?

This combined test build includes the recipes listed below. Lady Bug picture and sound are hardware-confirmed; newly added games need device testing. Four upstream alternative recipes lack matching chips in the local validation collection and are not listed. Cosmic Guerilla and Get A Way have no upstream recipes at the pinned revision.

Chips are matched by CRC and length, so renamed chips and merged/split ZIP sets work. Add parent ZIPs if needed. Missing or corrupt chips are reported beside the game.

Download individual ROMs or an SD-folder ZIP containing games under roms/Universal/. Extract at the SD-card root and install the core separately. Configuration and DIP defaults are built into the matching core; the image includes its game-specific PROMs. No separate sound PROM is required.

No copyrighted ROM data is included with this page.
